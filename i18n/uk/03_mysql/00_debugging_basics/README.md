# 00 Основи зневадження (debugging)

> Translation / Переклад: [English](../../../../03_mysql/00_debugging_basics/README.md)

Сформуйте простий робочий процес для швидкого та безпечного зневадження SQL-помилок.

## Мета

Зрозуміти, що саме пішло не так, ізолювати причину та перевірити виправлення з мінімальним ризиком.

## Поширені категорії помилок

- Синтаксичні помилки (`1064`)
- Відсутня таблиця/стовпець (`1146`, `1054`)
- Порушення обмежень (дубль ключа, помилки зовнішніх ключів)
- Помилки прав доступу

## Робочий процес зневадження

1. Відтворіть помилку якомога меншим запитом.
2. Прочитайте повний текст помилки та код.
3. Перевірте об'єкти схеми, які беруть участь (`SHOW TABLES`, `DESCRIBE <таблиця>`).
4. Перевірте припущення вузькими `SELECT`-запитами.
5. Внесіть невелике виправлення і повторно запустіть лише ту частину, що була змінена.

## Корисні команди

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p -D car_service_db -e "SHOW TABLES;"
mysql -h 127.0.0.1 -P 3306 -u root -p -D car_service_db -e "DESCRIBE customers;"
```

## Безпечна практика

- Використовуйте транзакцію під час тестування змін:

```sql
START TRANSACTION;
-- тестуйте UPDATE/DELETE/INSERT тут
ROLLBACK;
```

Повторюваний підхід до зневадження, придатний для всіх модулів SQL.
