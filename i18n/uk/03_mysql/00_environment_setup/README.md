# 00 Налаштування середовища

> Translation / Переклад: [English](../../../../03_mysql/00_environment_setup/README.md)

Підготуйте локальне середовище MySQL для всіх уроків у каталозі `03_mysql/`.

## Мета

Мати працюючий сервер MySQL і клієнтський інструментарій, щоб виконувати SQL-скрипти з цього репозиторію без перепон.

## Потрібні інструменти

- MySQL Server 8.x (або сумісний)
- CLI-клієнт MySQL (`mysql`)
- Опціонально: MySQL Workbench

## Кроки

1. Переконайтеся, що сервер MySQL запущено.
2. Переконайтеся, що CLI доступний:

```bash
mysql --version
```

3. Перевірте з'єднання:

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p -e "SELECT VERSION();"
```

4. Підтвердіть налаштування UTF-8:

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p -e "SHOW VARIABLES LIKE 'character_set_server';"
mysql -h 127.0.0.1 -P 3306 -u root -p -e "SHOW VARIABLES LIKE 'collation_server';"
```

## Чек-ліст

- [ ] Сервер MySQL працює
- [ ] Команда `mysql` доступна в терміналі
- [ ] З'єднання з локальним сервером встановлюється
- [ ] Кодування/сортування сервера перевірено

## Результат цього етапу

Ви готові імпортувати `car_service_db` і починати уроки SQL.
