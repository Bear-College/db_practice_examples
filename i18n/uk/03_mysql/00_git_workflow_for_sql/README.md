# 00 Git-процес для SQL

> Translation / Переклад: [English](../../../../03_mysql/00_git_workflow_for_sql/README.md)

Використовуйте полегшений Git-процес для SQL-вправ і код-ревʼю.

## Мета

Чітко відстежувати зміни в SQL і не втрачати напрацювання під час ітерацій над уроками.

## Гілкування

- Створюйте окрему гілку під задачу або блок уроку:

```bash
git checkout -b mysql/lesson-setup
```

## Звички фіксацій (commits)

- Тримайте коміти маленькими та сфокусованими за темою.
- Використовуйте зрозумілі повідомлення коміту:
  - `feat(mysql): add joins practice queries`
  - `docs(mysql): improve transactions notes`
  - `fix(mysql): correct foreign key in ddl script`

## Чек-ліст перед комітом

- [ ] SQL-скрипти виконуються без синтаксичних помилок
- [ ] Деструктивні команди застосовано свідомо
- [ ] Імена файлів відповідають конвенції іменування уроків
- [ ] Документація та SQL-приклади узгоджені

## Рекомендований чек-ліст для рев'ю

- Читабельність запиту та стилістична узгодженість
- Коректні з'єднання та предикати
- Усвідомлення індексів для важких запитів
- Безпека транзакцій для операцій запису

## Результат цього етапу

Передбачуваний процес версіонування та рев'ю для матеріалів навчання SQL.
