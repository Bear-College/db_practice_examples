# Змінні — `car_service_db`

> Translation / Переклад: [English](../../../../03_mysql/11_variables/variables_car_service_db.md)

Приклади показують **сесійні змінні користувача MySQL** (`@name`), **присвоєння** через `SET` / `SELECT`, використання в **`WHERE`** / **`LIMIT`**, **`PREPARE` / `EXECUTE`** і кілька **системних змінних** сервера/сесії (`@@…`). Скрипт працює з **`car_service_db`** (з **`01_database_mysql/car_service_db.sql.gz`**).

**Скрипт:** `11_variables/car_service_variables_examples.sql`

```bash
gunzip -c 01_database_mysql/car_service_db.sql.gz | mysql -u ... -p ... car_service_db
mysql -u ... -p ... car_service_db < 11_variables/car_service_variables_examples.sql
```

Запускайте файл **в одній клієнтській сесії**, щоб `@`-змінні зберігалися між інструкціями.

---

## Змінні користувача (`@user_var`)

| Тема | Примітки |
|------|----------|
| **Область видимості** | На всю сесію; зникають при закритті з'єднання. |
| **`SET @x = expr`**, **`SET @a = 1, @b = 2`** | Ініціалізація або оновлення. |
| **`:=` у `SELECT`** | Можна присвоювати й читати в одному запиті (важливий порядок обчислення). |
| **`SELECT @x := col FROM …`** | Зберегти значення із запиту (напр., агрегат). |
| **Використання в інструкціях** | `WHERE id BETWEEN @lo AND @hi`, `LIMIT @offset, @count` тощо. |
| **Очистити** | `SET @x := NULL` або перепідключитися. |

Користувацькі змінні **не** те саме, що **локальні змінні** всередині збережених програм (`DECLARE` — тут не розглядається).

---

## Системні змінні (`@@session` / `@@global`)

Читаються через **`SELECT @@session.variable_name`**, **`SHOW VARIABLES LIKE '…'`**. Деякі сесійні налаштування можна змінити через **`SET SESSION …`**; багато глобальних потребують прав. Скрипт лише торкається безпечних сесійних прикладів, де це зазначено.

---

## Блоки у `.sql`-файлі

1. `SET` меж діапазону → `SELECT` з **`work_orders`**.
2. Присвоєння агрегату змінній **`@avg_cost`**.
3. **`LIMIT`** з **`@offset`** / **`@page_size`**.
4. Шаблон лічильника рядків через **`@rownum`** (історичний; віконні функції зазвичай зрозуміліші).
5. **`PREPARE` / `EXECUTE`** з плейсхолдерами, прив'язаними до змінних користувача.
6. Читання **`@@version`**, **`@@session.transaction_isolation`** (та опціональне демо з **`sql_select_limit`** — закоментовано).
