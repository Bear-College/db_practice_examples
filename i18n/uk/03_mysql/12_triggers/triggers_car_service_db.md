# Тригери — `car_service_db`

> Translation / Переклад: [English](../../../../03_mysql/12_triggers/triggers_car_service_db.md)

Приклади встановлюють **InnoDB-тригери** на невеликих лабораторних таблицях **`tri_lab_account`** і **`tri_lab_audit`** усередині **`car_service_db`**. Демонструються **`BEFORE INSERT`** (валідація з **`SIGNAL`**), **`AFTER INSERT`**, **`BEFORE UPDATE`**, **`AFTER UPDATE`** і **`AFTER DELETE`**.

> **Назва теки:** цей модуль — **`12_triggers`** (тригери йдуть перед функціями у нумерації цього репо).

**Скрипт:** `12_triggers/car_service_triggers_examples.sql`

```bash
gunzip -c 01_database_mysql/car_service_db.sql.gz | mysql -u ... -p ... car_service_db
mysql -u ... -p ... car_service_db < 12_triggers/car_service_triggers_examples.sql
```

Використовуйте клієнт **mysql** (або сумісний); **`DELIMITER`** обробляється клієнтом, коли ви робите `SOURCE` або перенаправлення файлу.

---

## Поняття

| Момент | Типове використання |
|--------|---------------------|
| **`BEFORE INSERT` / `UPDATE`** | Валідація **`NEW.*`**, нормалізація значень, відмова через **`SIGNAL`**. |
| **`AFTER INSERT` / `UPDATE` / `DELETE`** | Запис аудит-рядків, лічильники (через **`NEW` / `OLD`**). |

- **`NEW`**: рядок, що вставляється, або нові значення стовпців при оновленні.
- **`OLD`**: попередній рядок при оновленні/видаленні.
- Тригери **не** замінюють обмежень, коли достатньо простого **`CHECK`** або **`FOREIGN KEY`** — використовуйте тригери для крос-рядкової логіки або логування.

---

## Що робить скрипт

1. Видаляє старі лабораторні об'єкти, створює **`tri_lab_account`** (мітка + баланс) і **`tri_lab_audit`** (журнал подій).
2. Створює п'ять тригерів; виконує приклади **`INSERT` / `UPDATE` / `DELETE`**.
3. Виконує `SELECT` з **`tri_lab_audit`** для перегляду подій.
4. Опціональний закоментований **`INSERT`**, який порушує правило (від'ємний баланс) → **`SIGNAL`**.
5. Опціональний **`DROP TABLE`** наприкінці для видалення лаб-об'єктів.

Щоб **видалити лише тригери** (зберігши таблиці): `DROP TRIGGER IF EXISTS tri_lab_account_bi_check;` (імена мають збігатися). **`DROP TABLE tri_lab_account`** видаляє цю таблицю разом з її тригерами.
