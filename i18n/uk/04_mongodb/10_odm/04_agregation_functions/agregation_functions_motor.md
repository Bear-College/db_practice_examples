# Агрегатні функції (`10_odm/04_agregation_functions`)

> Translation / Переклад: [English](../../../../../04_mongodb/10_odm/04_agregation_functions/agregation_functions_motor.md)

Приклади агрегацій Motor + MongoDB для:

- `$match` (фільтр)
- `$group` (групування)
- `$sum` (сума)
- `$avg` (середнє)
- `$count` (кількість)
- `$max`, `$min` (максимум/мінімум)
- `$sort` (сортування)
- `$project` (проєкція полів)

Значення за замовчуванням:

- `MONGODB_URI=mongodb://localhost:27017`
- `MONGODB_DB=edu_academy_seed`

Колекція:

- `odm_aggregation_orders`

## Запуск

```bash
pip install -r 04_mongodb/requirements.txt
python 04_mongodb/10_odm/04_agregation_functions/main.py
```
